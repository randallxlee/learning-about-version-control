# Learning about Version Control
Author: Randall Lee

Solving merge conflicts takes conscious effort, but I can do it!”

What I like most about version control is that it allows me to track changes in my code over time, collaborate with others seamlessly, and being able to revert to previous versions if something goes wrong. Using version control workflows allows me to manage my projects more efficiently and maintain a clear history of my development process.

What I find the most frustrating about version control is having to deal with merge conflicts. When multiple people make changes to the same part of a file, it can lead to conflicts that need to be resolved manually. This can be time-consuming and sometimes confusing, especially for beginners who are not yet familiar with the tools and processes involved in resolving these conflicts.
